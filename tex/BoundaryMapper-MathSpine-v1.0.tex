\section{Reversible Substrate}

Let $M$ be a smooth manifold and $U : M \to M$ a reversible operator.

\begin{definition}[Reversible Operator]
$U$ is reversible if there exists $U^{-1} : M \to M$ such that
\[
U^{-1}(U(x)) = x \quad \forall x \in M.
\]
\end{definition}

Reversible substrates preserve:

\begin{itemize}
    \item manifold continuity,
    \item geodesic adjacency,
    \item holonomy neutrality,
    \item drift-free evolution,
    \item full state recoverability.
\end{itemize}

The Tri-Altitude Spiral Specification provides a reversible baseline.

\section{Irreversible Substrate}

Irreversible substrates violate invertibility:

\begin{definition}[Irreversible Operator]
$U$ is irreversible if
\[
U^{-1}(U(x)) \neq x
\]
for some $x \in M$.
\end{definition}

Irreversibility arises from:

\begin{itemize}
    \item non-invertible nonlinearities,
    \item softmax collapse,
    \item context compression,
    \item attractor basin transitions,
    \item non-geodesic jumps,
    \item loss of latent manifold structure.
\end{itemize}

Transformers are canonical examples.

The Boundary Mapper uses the following invariants.

\subsection{Curvature}

\[

\subsection{Holonomy}

Parallel transport around a loop $\gamma = (x_1, \dots, x_n)$:
\[
H(\gamma) = \prod_{i=1}^n U(x_i).
\]

Holonomy deviation:
\[
\Delta H = \|H(\gamma) - I\|.
\]

\subsection{Lyapunov Exponent}

\[
\lambda_t = \log \|x_{t+1} - x_t\|.

\subsection{Fixed-Point Violation}

Solve:
\[
U(C) = C \quad \Rightarrow \quad (U - I)C = 0.
\]

Violation occurs if:
\[
\min |\lambda_i(U - I)| > 0.
\]

\subsection{Irreversibility Error}

\[
\epsilon_{\text{inv}} = \|U^{-1}(U(x)) - x\|.
\]
